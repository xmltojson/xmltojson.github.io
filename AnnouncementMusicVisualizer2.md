📂 **ADDING MUSIC IS NOW SIMPLER:**

✓ Choose one or multiple audio files  
✓ Drag and drop files directly into the application

✓ Follow progress and see file-specific errors

⌨️ **KEYBOARD SHORTCUTS:**

`Space` → Play / Pause  
`←` / `→` → Seek backward / forward 5 seconds  
`↑` / `↓` → Increase / decrease volume  
`M` → Mute / Unmute  
`F` → Toggle fullscreen
