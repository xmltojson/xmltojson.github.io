Dear Community,

We're thrilled to present our **Weather Widget** — a responsive weather dashboard that brings current conditions and forecasts to your screen with atmospheric photography, custom weather illustrations, and a polished dark design.

🎁 **WHAT'S INSIDE:**

🌤️ **Current Weather** — Temperature, feels-like temperature, and daily highs and lows  
🕒 **Hourly Outlook** — The next 12 hours with temperatures and precipitation chances  
📅 **7-Day Forecast** — Plan ahead with daily conditions and temperature ranges  
💧 **Weather Details** — Humidity, wind, cloud cover, precipitation, pressure, and daily maximum UV index  
🌅 **Sunrise & Sunset** — Local sunrise, sunset, and daylight duration  
🌙 **Day & Night Themes** — Weather-aware backgrounds with sun, moon, clouds, rain, snow, and fog illustrations  
🖼️ **Atmospheric Photography** — Scenic backgrounds that complement the weather—not live location views  
🌡️ **Temperature Toggle** — Switch between Celsius and Fahrenheit  
📍 **Geolocation** — Get weather for your current location with permission  
🔍 **City Search** — Find locations worldwide, including English and Ukrainian place names  

🖥️ **TECHNICAL HIGHLIGHTS:**

✓ Pure HTML, CSS, and JavaScript — no frameworks or build tools  
✓ No API key required for the public services used  
✓ Weather and forecasts powered by Open-Meteo  
✓ Compact desktop layout designed for normal 100% browser zoom  
✓ Responsive tablet and mobile layouts with touch-friendly controls  
✓ Local storage for your location, temperature preference, and latest forecast  
✓ Automatic refresh checks every 15 minutes while the page is visible  
✓ Keyboard accessibility and reduced-motion support  
✓ Clear update timestamps and saved-data indicators  

🎯 **PERFECT FOR:**

• Checking conditions before your daily commute  
• Planning outdoor activities  
• Learning responsive web development  
• Educational coding demonstrations  
• Exploring weather APIs and browser geolocation
