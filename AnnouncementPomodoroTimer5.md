I'm excited to introduce **Pomodoro Timer / Forest** — a calm, nature-inspired web application that helps you focus on one task at a time and make room for meaningful breaks.

Built around the Pomodoro Technique, it pairs customizable work sessions with a peaceful forest setting and simple, distraction-free controls.

🎁 **WHAT'S INSIDE:**

🎯 **Focus Sessions** — Customize your work intervals, starting with the classic 25 minutes  
☕ **Short & Long Breaks** — Build a sustainable rhythm of concentration and rest  
🌲 **Forest-Inspired Design** — A scenic background, translucent panels, and a circular countdown  
📝 **Current Task** — Keep one meaningful goal visible while you work  
📊 **Progress Tracking** — See completed pomodoros, completed focus time, and cycle progress  
🔄 **Auto-Start Options** — Choose whether breaks and focus sessions start automatically  
🎵 **Gentle Completion Chimes** — Optional audio alerts when a session ends  
🔔 **Desktop Notifications** — Optional browser alerts where supported and permitted  
ℹ️ **Built-in Guide** — Learn the basics of the Pomodoro Technique without leaving the app  
⚙️ **Flexible Settings** — Adjust durations, cycle length, sound, and automatic transitions  

🖥️ **THOUGHTFULLY BUILT:**

✓ Pure HTML, CSS, and JavaScript — no frameworks or installation required  
✓ Local browser storage for your task, settings, timer state, and progress — no account needed  
✓ Ukrainian 🇺🇦 and English 🇬🇧 with instant switching  
✓ Light and dark themes  
✓ Responsive layouts for desktop, tablet, and mobile — comfortable at 100% desktop zoom  
✓ Deadline-based timing that restores the remaining time after a reload  
✓ Keyboard shortcuts: `Space` to start or pause, `R` to reset, `S` to skip, and `I` for help  
✓ Confirmation dialogs before resetting progress or skipping a session  
✓ Visible keyboard focus and reduced-motion support  

🎯 **PERFECT FOR:**

• Students preparing for exams  
• Remote workers and freelancers  
• Developers setting aside focused coding time  
• Writers building a consistent routine  
• Anyone who wants a gentler, more intentional approach to productivity  

🔗 **Try it here:** https://pomodorotimerj.github.io

Your progress stays in your current browser, without cloud synchronization. Keep the page open for completion alerts; if you close it, the timer state is restored when you return.
