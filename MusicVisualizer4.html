Selecting multiple files on a phone

Android: use Browse files, open Files / Documents, then touch and hold one file and tap the others. Tap Open or Select.

iPhone / iPad: use Browse files, open Browse in the Files picker, then use Select or the selection circles if shown.

If your file provider only allows one file, use Add more files repeatedly. Your selections stay in this list and upload together. A webpage cannot force an unsupported native picker to allow multi-selection.

Desktop: use Ctrl / Cmd or Shift to select multiple files. Only audio files are accepted here. Files stay on this device; library limit: 200 MB.
